The App is a read-only companion that displays Claude Code usage figures served
by **Claude Usage Tracker**, a separate macOS application running on your own
Mac. The App does not generate usage data, does not connect to Anthropic, and
cannot function without that Mac application and a network path to it.

To use the App you must:
